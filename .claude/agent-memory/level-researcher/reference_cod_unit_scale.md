# CoD Series Unit Scale and Architectural Standards

Source: Call of Duty 5 Gameplay Standards wiki (wiki.zeroy.com) — standards carry forward across MW series.

## Unit Conversion
- 1 unit = 1 inch = 0.0254 meters (2.54 cm)
